# 🎲 Jogo dos Dados

Um jogo interativo desenvolvido com HTML, CSS e JavaScript, onde dois jogadores competem lançando dados para descobrir quem obtém o maior número.

## 🔗 Live Demo

👉 https://devdiegorosa.github.io/jogo_dos_dados/

---

## 👨‍💻 About the Project

Este projeto consiste em um jogo simples e divertido de dados executado diretamente no navegador.

O objetivo é simular o lançamento de dois dados de forma aleatória e determinar automaticamente o vencedor de cada rodada, proporcionando uma experiência dinâmica e interativa para o usuário.

---

## 🚀 Features

* 🎲 Geração aleatória de números (dados)
* 🏆 Sistema automático de vencedor
* 🔄 Atualização dinâmica da interface
* 🎨 Interface simples e intuitiva
* ⚡ Execução rápida diretamente no navegador

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Random Number Generation
